# Essco.Portal

Es el sitio público y portal de clientes de ESSCO, separado del ERP Syncro Cliente.

- **Debe contener:** presentación comercial, registro y área de cliente del portal.
- **No debe contener:** reglas internas del ERP ni consultas directas a las tablas operativas de Syncro Cliente.
- **Dependencias:** ASP.NET Core y el modelo propio del portal.
- **Ejemplo:** el cliente autenticado consulta las aplicaciones asignadas y abre Syncro Cliente mediante el enlace configurado.
