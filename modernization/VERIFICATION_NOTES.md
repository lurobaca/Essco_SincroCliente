# Verificación de la migración

La compilación debe ejecutarse con `dotnet build Essco.Modern.sln --no-restore` antes de las pruebas. Ejecutar únicamente `dotnet test` no demostró que Razor Pages compilara.

La revisión completa detectó y corrigió referencias a un permiso inexistente de inventario, colisiones entre métodos y propiedades From, ocultamiento del método File y una directiva Razor mal situada. La web, el worker y las bibliotecas compilan juntos.

Los adjuntos de vacaciones, incapacidades y préstamos admiten imágenes PNG/JPEG hasta 5 MB. Se conserva la columna binaria Adjunto, se comprueba el empleado en consultas y actualizaciones y no se modifica un movimiento anulado. La descarga es un archivo adjunto, no contenido HTML embebido. La comprobación de firma identifica el tipo; no sustituye un antivirus. Debe probarse contra una copia SQL con documentos reales.

La matriz FUNCTIONAL_PARITY.md sigue abierta. La compilación y las pruebas automatizadas no acreditan paridad completa, compatibilidad bancaria, emisión Hacienda ni ejecución correcta de procedimientos almacenados externos.
