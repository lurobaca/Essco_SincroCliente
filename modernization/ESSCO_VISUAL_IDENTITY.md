# Identidad visual ESSCO

Referencia proporcionada por el usuario: identidad de cotización, aplicada a las interfaces existentes; no implica generar una cotización ni cambiar reglas tributarias.

- Marca exclusivamente tipográfica: ESSCO.
- Nombre: Easy Software Solution Company.
- Eslogan: Un mundo con menos clic.
- Blanco predominante; marino #102d50; azul #175fc4; azul oscuro de interacción #124c9d; paneles #eff5fd; divisiones #d6e2ef.
- Sin isotipo ni recuadro con la letra E. No agregar símbolos al wordmark.
- Avisos, errores y acciones destructivas conservan textos y comportamiento. Se usan bordes diferenciados y variaciones azules en lugar de depender de rojo, verde o naranja.

Portal y ERP cargan essco-brand.css después de sus estilos originales. Los dos archivos deben permanecer idénticos para no separar la identidad entre aplicaciones. Las plantillas de acceso, portal y ERP comparten wordmark y eslogan. No se modificaron archivos de Bootstrap de terceros.

Test-BrandIdentity.ps1 comprueba igualdad de hojas de marca y referencias de las tres plantillas. No sustituye revisión visual, pruebas con lectores de pantalla ni una auditoría completa de accesibilidad.
