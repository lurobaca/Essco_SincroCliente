# Diferencias conocidas

- La interfaz nueva será web y no reproducirá literalmente ventanas ni controles WinForms.
- El prototipo de trabajos SAP usa memoria y no comunica todavía procesos separados.
- SAP DI API, Hacienda, bases de datos, certificados, impresoras y reportes no se han validado contra ambientes reales.
- Autenticación y autorización empresarial están pendientes del inventario de usuarios y permisos.
